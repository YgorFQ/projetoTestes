# Dados legados de Notas da equipe

Estes arquivos preservam o conteudo criado pelo fluxo antigo para futura
migracao controlada ao Firestore. Nao edite esta pasta para criar ou atualizar
notas: ela nao e carregada pelo aplicativo e nao participa do CRUD oficial.

Depois de validar a importacao de todo o conteudo no Firestore e um backup
restauravel, esta pasta pode ser removida em uma mudanca separada.
