# Documentacao legada

Os arquivos desta pasta descrevem fases anteriores do SenkoLib e sao mantidos
como memoria tecnica. Eles podem citar caminhos, persistencia GitHub e fluxos
que nao sao mais oficiais.

Para implementar ou operar o sistema atual, comece em `docs/README.md`. Nao
copie uma instrucao desta pasta para o codigo sem confirmar a arquitetura
canonica e o inventario de classificacao.
